What is a dataset? A dataset is a large collection of labeled examples used to teach a model. MNIST contains 70,000 images of handwritten digits (0–9), each 28×28 pixels in grayscale. The model learns patterns from the training split and is evaluated on the test split it has never seen.
🎯 Classification Task

Binary Classification

Distinguish exactly 2 classes. The model outputs a single probability.

Multiclass Classification

Distinguish 3 or more classes using softmax output.

Binary vs Multiclass: In binary classification the model outputs one probability (e.g. "Is this a 3 or a 7?"). In multiclass classification the model outputs a probability for every class and predicts the highest one (e.g. "Which digit 0–9 is this?").

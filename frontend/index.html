What You Can Do with MLForge

🗄️

Choose Real Datasets

Start with MNIST handwritten digits. Select binary or multiclass classification tasks — the architecture adapts automatically.

🧠

Visual Model Builder

Add Conv2D, MaxPooling, Dense, Dropout and more layers by clicking — no code. Reorder, configure, and understand each layer's role.

⚡

Remote Training

Your model is trained on the server using TensorFlow/Keras — not in your browser. Real training, real results.

📈

Live Progress

Watch accuracy and loss curves evolve in real time during training. Learn to spot overfitting and underfitting as they happen.

📊

Full Evaluation

See accuracy, precision, recall, F1-score and a confusion matrix. Each metric is explained in plain English.

📦

Model Export

Download your trained model as .keras or TensorFlow Lite .tflite, plus JSON files for the architecture and history.

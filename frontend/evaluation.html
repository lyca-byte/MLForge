📈 Accuracy Curve
Accuracy: The fraction of predictions that were correct. Watch for a gap between training and validation accuracy — a large gap suggests overfitting.
📉 Loss Curve
Loss: How wrong the model's predictions were, on average. Lower is better. Validation loss rising while training loss falls = overfitting.

Confusion Matrix: Each row is the true class; each column is what the model predicted. Diagonal cells (top-left to bottom-right) are correct predictions. Off-diagonal cells are errors. Bright cells indicate high counts.

Precision: Of all predictions for a class, how many were actually that class?
Recall: Of all actual samples in a class, how many did the model find?
F1: Harmonic mean of precision and recall — useful when classes are imbalanced.
🧠 Model Information
Why parameters matter: A model with many parameters can learn complex patterns but also tends to overfit and requires more data and compute. For MNIST (28×28 grayscale), a relatively small model often suffices.
